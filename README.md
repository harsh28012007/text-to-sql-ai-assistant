#  Amazon Text-to-SQL AI Assistant

### Transform Natural Language into Database Insights

An AI-powered analytics platform that converts plain English questions into SQL queries, enabling users to retrieve and visualize database insights without SQL knowledge.


##  Overview

Developed a Text-to-SQL system that allows users to interact with databases using natural language. The application automatically generates SQL queries, retrieves data from a SQLite database, and presents insights through an interactive dashboard.



##  Key Features

*  Natural Language Query Processing
*  Automatic SQL Query Generation
*  Real-Time Data Retrieval
*  Interactive Streamlit Dashboard
*  Product & Category Analytics
*  Data Visualization & Reporting
*  FastAPI REST API Integration



##  Tech Stack

##  System Architecture

```text

    ↓

    ↓
SQLite Database
    ↓
Analytics Dashboard
```
